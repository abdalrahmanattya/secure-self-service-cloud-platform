# Interface reference

These pages document the implemented Milestones 5–7 surface. Environment
validation, simulation, deterministic proposal creation/status, and portal
proposal evidence are locally executable. They expose no direct Terraform or
cloud operation.

- [API reference](api.md)
- [CLI reference](cli.md)
- [Portal reference](portal.md)

All interfaces inherit provider and mode from the active installation.
Callers cannot switch AWS/Azure per request.
